# Margin — 読む、その先へ。

PDF の気になる箇所を選び、CLI の AI と読み解くローカル Web アプリです。

PDF・書籍本文・認証情報は同梱していません。利用する PDF と、各 AI サービスのアカウントはご自身で用意してください。OpenAI・Cognition・出版社の公式製品ではありません。

## 起動

Node.js 22.13 以降が必要です。推奨は Node.js 24 で、この環境と CI でも 24 を使用します。パッケージ管理には、`package.json` でバージョンと SHA-512 を固定した pnpm 11.27.0 を使います。

```sh
corepack enable pnpm
pnpm install --frozen-lockfile
pnpm run dev
```

`corepack enable` を使えない環境では、各 `pnpm` コマンドを `corepack pnpm` に置き換えて実行できます。初回の取得時に、Corepack が固定された pnpm のハッシュを検証します。

ブラウザーで **http://127.0.0.1:4317** を開きます。サーバーはループバックアドレスのみに接続します。

配布用ビルドで動かす場合：

```sh
pnpm run build
pnpm start
```

「PDF を開く」またはドラッグ＆ドロップで、ご自身の PDF を追加できます（最大 100 MB）。追加ファイルはこのブラウザーの IndexedDB に保存されます。プロジェクト直下に `pdf/` フォルダーを作り、その直下へ置いた PDF もライブラリーに表示されます。`pdf/` がなくても起動できます。このフォルダーと PDF ファイルは Git の管理対象外です。

## できること

- PDF のページ移動、拡大・縮小、埋め込まれた目次、しおり、読書位置の復元
- PDF 内のリンクをクリックして、外部サイトを別タブで開く・参照先のページへ移動（テキストモード）
- 本文のドラッグ選択。選択箇所はページ内にハイライトして保持
- 図・数式・スキャンされた文章の範囲選択。Codex には切り抜いた PNG も共有
- 選択部分、ページ番号、そのページの本文、直近の会話を添えた質問
- Codex / Devin の切り替えと、CLI 実行ファイルの検出
- Markdown・数式・Mermaid 図・折れ線/棒グラフ・HTML/JavaScript のインタラクティブ解説
- 説明のスタイル指定、追加質問、回答の停止、エラー後の再送信
- PDF ごとの会話保存、引用箇所への移動、Markdown での会話書き出し
- AI を呼ばずに試せる解説表示のサンプル

## CLI 接続

アプリが新しい API キーを管理する必要はありません。インストール済み CLI の認証を使います。利用枠・料金は各 CLI のアカウント設定に従います。

### Codex

ターミナルで先に認証します。

```sh
codex login
```

`codex exec` に標準入力でプロンプトを渡し、`--output-schema` と `--output-last-message` で構造化回答を受け取ります。選択画像は `--image` で渡します。

シェル実行・複数エージェント機能を無効にし、読み取り専用サンドボックスと一時作業ディレクトリーで実行して、`--ephemeral` を使用します。`--ignore-user-config` により個人用の MCP やカスタム指示を取り込みません。モデルを指定する場合は `.env` の `CODEX_MODEL` を使ってください。検証済み：`codex-cli 0.155.1`。古い CLI で未対応フラグのエラーが出る場合は更新してください。

### Devin

このプロジェクトのターミナルで `devin` を一度起動し、ログインと、必要な場合はワークスペースの信頼確認を完了してください。

`devin --print --permission-mode auto --prompt-file ...` を呼び出します。信頼チェックと CLI の承認設定は維持します。作業ディレクトリーはこのプロジェクトです。現時点の標準アダプターは **テキスト入力** です。画像だけの範囲は Codex を使用してください。

検証済み：`devin 3000.10.27`。本文解説・Mermaid 図の JSON 出力を取得できています。

### 任意の CLI を追加

`.env.example` を参考に `.env` を作ります。変更後はサーバーを再起動してください。

```dotenv
PORT=4317
CODEX_BIN=/absolute/path/to/codex
DEVIN_BIN=/absolute/path/to/devin
# CODEX_MODEL=your-model
# DEVIN_MODEL=your-model
AI_TIMEOUT_MS=300000
AI_PROVIDERS_FILE=./providers.local.json
```

`providers.local.json` の例：

```json
[
  {
    "id": "my-ai",
    "name": "My AI",
    "command": "/absolute/path/to/my-ai-wrapper",
    "args": ["--prompt-file", "{promptFile}"],
    "supportsImages": false,
    "description": "カスタム CLI"
  }
]
```

プロンプトは標準入力にも渡します。引数では `{promptFile}`、`{schemaFile}`、`{imageFile}`、`{outputFile}` を使えます。ラッパーは標準出力、または `{outputFile}` に回答を返してください。JSON 形式は `src/lib/schema.ts` が定義しています。通常のテキストも Markdown として表示できます。画像に対応するラッパーだけ `supportsImages: true` としてください。

コマンドと引数はサーバー起動時のローカル設定で決まります。ブラウザーから実行コマンドを指定することはできません。プロセスは `shell: false` で起動します。

## データの扱い

PDF の表示・文字抽出はブラウザー内の PDF.js で行います。質問時に、選択した本文（最大 16,000 文字）、現在ページの本文（最大 24,000 文字）、ページ番号とファイル名、直近 10 メッセージを CLI に渡します。Codex には選択範囲の画像、未選択なら現在ページの画像も添付します。**PDF 全体のアップロードや自動インデックス作成は行いません。** CLI の AI サービスには上記の文脈が送信されます。

会話・しおり・読書位置はブラウザーの localStorage に保存します。会話履歴は各 PDF 最新 80 メッセージで、切り抜き画像を履歴に重複保存しません。ブラウザーのデータを削除すると履歴・取り込んだ PDF は消えるので、必要な会話は書き出してください。`localhost` と `127.0.0.1` は異なる保存先です。同じ URL で使ってください。

AI が生成した HTML は `sandbox="allow-scripts"` の iframe に表示し、親ページへのアクセス、フォーム送信、外部リソース読み込みや fetch を CSP で制限します。図はスクリプトを許可しない別の iframe で表示します。CLI 自体のツール権限は各 CLI の権限制御に依存します。プロンプトにも、ファイル操作やコマンド実行をせず解説だけを返すよう指定しています。

ローカルで動くのはビューワーと連携用サーバーです。**AI に送信した内容の保存・学習利用・保持期間は、各サービスの契約とアカウント設定に従います。** 一時ファイルの削除や Codex の `--ephemeral` は、AI サービス側のデータ削除や学習利用の無効化を保証するものではありません。機密情報や個人情報を含む資料を使う場合は、送信前に扱いを確認してください。

## 資料の権利と利用について

- AI サービスへの送信を含め、その用途で適法に利用できる資料を使ってください。購入済み・個人学習用であることだけで、すべての利用が認められるわけではありません。資料の利用条件、各 AI サービスの規約、適用される法律を確認してください。
- AI の解説には誤りが含まれます。原典の記述と照合し、著者の主張と AI が補った例・推測を区別してください。
- 書き出した読書ノートには、選択した本文の引用が含まれます。ノート、ページ画像、スクリーンショット、生成した解説を公開・共有する場合は、元の資料の権利や引用の要件を別途確認してください。
- デモや不具合報告には、自作または公開・再配布が許可された資料を使ってください。書籍本文、個人情報、認証情報を Issue や Pull Request に貼らないでください。

著作権に関する参考資料：[文化庁「AI と著作権について」](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)。本プロジェクトの MIT ライセンスは、利用者が読み込む PDF や第三者の著作物に利用許諾を与えるものではありません。

## 構成

```text
src/
  App.tsx                       ライブラリー・会話・質問の状態
  components/PdfViewer.tsx       PDF.js、本文/範囲選択、画像切り抜き
  components/ExplanationView.tsx Markdown / 図 / グラフ / インタラクティブ表示
  lib/schema.ts                 質問と解説の型・検証
  lib/storage.ts                ブラウザー内保存
  lib/api.ts                    NDJSON 応答の受信
  lib/frames.ts                 iframe の文書と CSP
server/
  app.ts                        ローカル API、リクエスト認証・制限
  providers.ts                  CLI アダプター、タイムアウト・停止・一時ファイル処理
  prompt.ts                     文脈構築、出力スキーマ、回答検証
  index.ts                      Express + Vite / ビルド済みファイルの配信
```

API は Host / Origin / Sec-Fetch-Site とセッショントークンを確認します。回答は進捗通知と最終結果を NDJSON で返します。実行上限は同時 2 件、既定のタイムアウトは 5 分です。停止ボタンは質問ごとの専用キャンセル API を呼び、CLI の終了と一時ファイルの削除を確認してから停止完了を表示します。通信切断時も子プロセスのグループへ停止を送ります。通常の停止に応じない場合は 1.5 秒後に強制終了します。停止クリックで次の質問が送信されないことも回帰テストで検証しています。

## 検証

```sh
pnpm run check
pnpm test
pnpm run build
```

実際の AI への疎通テストは明示的に実行できます（通常のテストでは AI を呼びません）。架空の短い教材文を使用します。

```sh
pnpm run test:ai codex
pnpm run test:ai devin
```

自動テストでは、HTTP アクセス境界、PDF 配信・リンク、文脈の受け渡し、出力形式、グラフデータ、CSP、標準入力の安全な受け渡し、キャンセル・起動失敗を検証します。PDF のリンクテストは `tests/fixtures/pdf-links.ts` からメモリー上に生成するオリジナルの小さな PDF を使い、市販書籍やローカルの `pdf/` フォルダーには依存しません。

GitHub Actions は Node.js 24 と固定した pnpm で、ロックファイルを変更しないインストール、レジストリ署名検証、既知の脆弱性検査、型チェック、テスト、ビルドを実行します。通常のテストと CI に AI の認証情報は不要です。実際の AI を呼ぶ `test:ai` は CI では実行しません。

## 現在の範囲

- 1 ページ単位のビューワーです。ページをまたぐ一括選択・全文検索・全文 RAG は未実装です。
- スキャン PDF の文字選択には OCR が必要です。現状は範囲選択と Codex の画像入力で質問できます。
- パスワード付き PDF は、解除したファイルを開いてください。
- 認証済みでも利用枠やネットワーク状態により CLI が失敗することがあります。画面に原因を表示します。
- インタラクティブ解説の内容・図の正確さは AI の出力に依存します。不正な Mermaid はソース表示にフォールバックします。

## 依存関係とサプライチェーン対策

設定は [pnpm-workspace.yaml](pnpm-workspace.yaml)、更新時の手順と制限は [SECURITY.md](SECURITY.md) を参照してください。

- 直接依存を完全なバージョンで固定し、間接依存を含む `pnpm-lock.yaml` を管理します。通常のセットアップには `pnpm install --frozen-lockfile` を使います。
- 公開後7日未満のパッケージと公開日時を確認できないパッケージは拒否します。既存のロックファイルにも公開日・信頼性の検査を適用します。
- 依存パッケージのインストールスクリプトは実行しません。現在の `esbuild` と `fsevents` は明示的に不許可とし、未審査のスクリプトが増えたらインストールを失敗させます。
- 配布時の信頼性が低下した版や、間接依存が持ち込む非標準の配布元を制限します。
- GitHub Actions はコミット SHA で固定し、読み取り専用権限・認証情報を保存しない checkout を使います。CI では依存キャッシュを共有しません。
- Dependabot が週1回、依存と Actions の更新 PR を提案します。通常の更新は7日待機し、自動マージはしません。

これらはリスクを減らす対策であり、安全性の保証ではありません。スクリプトの禁止は、テスト・ビルド・アプリ実行時に読み込む依存コードを隔離するものではありません。

## 開発・公開時の注意

変更後は上記の型チェック・テスト・ビルドを実行してください。PDF 関連の不具合には、実物の書籍を追加する代わりに、再現に必要な最小限の自作データを使います。

`.gitignore` は PDF、`pdf/`、`.env` とその派生ファイル（`.env.example` を除く）、`providers.local.json`、CLI のローカル設定、`*-notes.md`、`screenshots/`、ビルド成果物を除外します。別名で保存した画像や読書ノートまで自動判別するものではないため、コミット前には `git status --short` と差分を確認してください。既に追跡されたファイルや過去のコミットは `.gitignore` では削除されません。

このアプリは各利用者の端末で実行する構成です。インターネットへサーバーを公開する場合は、認証・データ管理・サービス契約などを別途設計する必要があります。
